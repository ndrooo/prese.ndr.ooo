What's a custom element?

  • Web frameworks have had "components" for modularization for a long time
  • From 2018-2019, standardized Web Components API!
  • Three parts
    • HTML templates
    • Shadow DOM (spooky)
    • Custom elements

Composable, declarative behaviors

Here's a

Custom elements have a hyphen: <my-element>

We can handle attribute updates: <my-element instant="update">

They're flexible

Because they just use tags and attributes!

Vanilla JS: document.getElementsByTag("my-element")[0].setAttribute("is-cool", coolness)

AlpineJS: <my-element :is-cool="coolness"></my-element>

React: return (<my-element is-cool={coolness}></my-element>);

Jinja: <my-element is-cool="{{coolness}}"></my-element>
